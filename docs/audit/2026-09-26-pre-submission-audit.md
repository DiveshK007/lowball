## BLOCKERS

### B1 — A fresh clone cannot run the contract tests
`npm test --prefix contract` on a clean clone of `main`:

```
Error: Cannot find module '../managed/lowball/contract/index.js'
      Tests  no tests
```

`contract/src/managed/` is git-ignored and must be generated by `npm run compact`
first, but README → *Run Tests* says only `npm test --prefix contract   # 27 tests`.
A reviewer following the README hits a failing suite as their first action.
`contract/package.json` already has `test:compile` (`npm run compact && vitest run`),
which the README never mentions.
**Verified:** cloned to `/tmp/freshclone`, ran the README steps literally.

### B2 — README's toolchain smoke test uses a path that does not exist
README says:
```
cd contract
compact compile hello-world.compact managed/hello-world
```
The file is at `contract/src/hello-world.compact`, and the working script is
`compact compile src/hello-world.compact src/managed/hello-world`.
**Verified:** `hello-world.compact` is absent from `contract/`; `git ls-files`
shows `contract/src/hello-world.compact`.

### B3 — README tells you to install an unpinned Compact toolchain
README: `compact update` then *"expect: compact compile --version 0.31.x"*. A bare
`compact update` installs the newest toolchain (0.34.0), which emits contracts
requiring `@midnight-ntwrk/compact-runtime` 0.19.x while `contract/package.json`
pins `^0.16.0`. That is the exact mismatch that broke CI for twelve days
(decisions log §10, 2026-09-05); CI now pins `compact update 0.31.1` but the
README does not.

### B4 — No Google Sheet for feedback
`docs/FEEDBACK.md`: *"not yet created — paste the link here."*
`VITE_FEEDBACK_FORM_URL` is `''`. A `FEEDBACK.md` with no Sheet is an explicit
rejection criterion, and the app currently shows no feedback link after a bid.

### B5 — Zero verified users
`docs/USERS.md`: **Distinct verified wallets: 0** (from 0 rows). L5 needs 50,
L6 needs 70. The verification tooling works; there is simply no input yet.

### B6 — Demo video is stale
`https://youtu.be/om0mTpbdXiU` was filmed against the Preview single-drop build.
It does not show multi-drop, the bid accumulator, stock enforcement, the sold-out
path, or the wallet picker. Shot list ready at `docs/demo-video-script.md`.

### B7 — No L5 submission checklist
`docs/submissions/` has L1–L4 and L6. L5 is the next submission and has no
checklist, so no requirement-to-evidence mapping exists for it.
